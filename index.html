I work on tiny object detection, semantic segmentation, lightweight CNN and CNN-Transformer architectures, attention, feature fusion, and model diagnostics.

The goal is not to add complexity for its own sake. It is to understand which part of the pipeline changes the result: representation, geometry, ranking, confidence, or assignment.

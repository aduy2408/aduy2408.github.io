CLM-Net

A Channel-Optimized Lightweight Hybrid Network for Varroa Mite Segmentation

CLM-Net replaces expensive full-channel attention with partial neighborhood attention and a lightweight global bottleneck. The project studies how to preserve useful context while keeping the model small.

03Medical image preprocessingAPWeb 2026

DICOM Preprocessing for Lung Detection

Comparative preprocessing of chest X-ray data for object detection

This work studies DICOM preprocessing methods for chest X-ray detection, including raw min-max normalization, histogram equalization, percentile clipping, VOI LUT, adaptive percentile processing, and CLAHE. The pipeline evaluates single and combined representations with YOLOv8, Faster R-CNN, and RT-DETR.

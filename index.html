I am Duy Le, a researcher and developer based in Da Nang, Vietnam. My work focuses on tiny object detection, semantic segmentation, lightweight neural networks, and the careful analysis of how model changes affect representation, localization, ranking, and confidence.

I work directly with research code in PyTorch, modifying model internals, feature-fusion blocks, attention modules, detection heads, loss functions, and evaluation pipelines.

LMSCA-YOLO

Lightweight Multi-Scale Compressed Attention for Tiny Varroa Mite Detection

A lightweight detector designed for tiny Varroa mites in bee imagery. The method combines IRDCB multi-scale fusion, Scale-Aligned Gated Residual Injection, deformable refinement, and Key-Value Compressed Attention.

02Semantic segmentation

CLM-Net

A Channel-Optimized Lightweight Hybrid Network for Varroa Mite Segmentation

CLM-Net replaces expensive full-channel attention with partial neighborhood attention and a lightweight global bottleneck. The project studies how to preserve useful context while keeping the model small.
